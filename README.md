# data-science-netflix-project
An exploratory data analysis project to identify trends in Netflix movie durations from the 1990s using Python and pandas.

# 🎬 Netflix Movie Duration Analysis (1990s)

This project explores Netflix movie data to uncover trends in movie durations from the 1990s. The goal was to identify the most common movie duration during the decade and count the number of short action movies.

---

## 📊 Objectives

- Filter Netflix data to include only movies released between 1990 and 1999.
- Identify the most frequent movie duration in that period.
- Count how many action movies were under 90 minutes.

---

## 🔧 Tools & Libraries

- Python
- pandas
- matplotlib

---

## 📁 Data Source

- `netflix_data.csv` (Netflix content dataset)
- Key columns used:
  - `type`
  - `release_year`
  - `duration`
  - `genre`
